# linkedin-media

Public media host for LinkedIn posts (images, PDF carousels).

Buffer's API fetches post media **server-side**, so every asset must live at a
publicly reachable URL. This repository is that host: files here are referenced
directly via `https://raw.githubusercontent.com/andreasbigert/linkedin-media/main/...`.

## Why public

`raw.githubusercontent.com` URLs for a private repo are not fetchable by Buffer, so
the repo must be public. The contents are assets that are published to LinkedIn
anyway — nothing here is private.

> **Consequence:** redaction is permanent. A leaked key in an image is public even
> after the post is deleted. `media_publish.py` runs a scrub gate before uploading.

## Layout

    media/<YYYY-MM-DD>-<slug>/slide-01.png ...
                             /carousel.pdf
                             /thumb.png

## Generated by

`~/knowledge/media_kit.py` (build) and `~/knowledge/media_publish.py` (upload).
